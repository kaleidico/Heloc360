# HELOC360 robots.txt

# Kept deliberately short. The previous version blocked /_next/, *.js and *.css for
# `User-agent: *` — rules that would stop a crawler rendering the site as users see it.
# They never actually applied to Google or Bing (a crawler obeys only its most specific
# group, and both had their own group below), but the file was one deletion away from
# them biting. It also blocked *.txt$, which covered the llms.txt we publish on purpose.

User-agent: *
Allow: /
Disallow: /api/
Disallow: /studio/
